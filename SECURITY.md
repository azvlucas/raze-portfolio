# Security policy

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature for this repository. Do not open a public issue containing exploit details, credentials, personal data, or infrastructure information.

Include the affected component, reproduction steps, impact, and any suggested mitigation. Reports will be reviewed as promptly as possible.

## Supported version

Only the current default branch of this portfolio snapshot is maintained.

## Scope note

This public repository excludes production secrets, customer data, deployment configuration, and private operational history. The included database seed is synthetic and intended only for local evaluation.
